# PickleStay — Hotel Management System

PickleStay is a simple hotel management system written in Python by Parikshith. This repository implements booking, check-in/check-out, and room management using Python with pickle-based persistence.

Features
- Booking creation and management
- Check-in / Check-out workflows
- Room availability and simple reporting
- Data persisted using Python's pickle module (single-file persistence)

Quick start
1. Clone the repository:
   git clone https://github.com/bookspdf705-coder/picklestay.git
2. Enter the project directory and run:
   python main.py

Requirements
- Python 3.8 or newer
